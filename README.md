桔子数科事件整理

一、暴雷事件的开始

2026年5月至6月，中国互联网各大社交平台、投诉类平台开始大规模出现用户爆料。大量用户反馈，自己在桔子数科相关平台的网络借贷明明已经还款，但仍遭到资方强行划扣，且实时征信显示用户未还款。

目前互联网普遍了解的暴雷原因，是平台宣传并引导用户进行刷单，告知用户：

“短期免息借款，借完即还赚佣金，每单60-75元。”

用户在平台申请6000-8000元贷款，到账后转入桔子数科账户，代理随即发放佣金，APP同步显示账单结清。

不少人为了赚取佣金，可能刷了几十单。用户以为自己的每一笔借款均在第一时间全额还款，没有任何欠款。

但平台并未把这些资金给到实际出资的一众持牌消费金融及银行机构，反而对资金进行截留、挪用。而资方仍按照协议持续向借款人进行催收，并向征信系统报送逾期记录。

二、刷单还款可能只是冰山一角

以上是目前爆料出的信息。

用户一般只关心两个问题：

1. 自己的征信是否会恢复；
2. 借款合同是否能够确认已经履约。

然而，用户刷单涉及的金额可能只是冰山一角，很少有人继续深究其暴雷的根本原因，以及被截留的资金究竟去了哪里。

这背后其实是一场精心策划已久的庞氏骗局。

公司各个实体的法人及实控人主要包括：

四、从桔子分期到桔多多

该公司长期打着助贷的名义，做着网络小额贷款的生意。

其前身是桔子分期。校园贷暴雷后被监管部门叫停，2017年摇身一变，更名为桔多多。

2025年10月新政之前，其贷款年化利率长期维持在36%，客户群体主要是银行不愿意做的高风险用户。

2025年10月新政之后，其大部分产品贷款年化利率下调至20%，但如此高的利率依旧亏损。

核心原因就是其用户群体风险过高，坏账率极高。贷款年化利率下调至20%后，已经不足以使其继续实现盈利。

五、2025年10月新政后的变化

2025年10月新政后，一场精心设计的变种庞氏骗局就此展开。

首先，桔子数科将慧聚科瀚进行了名义上的剥离与搬家，公司旗下多款APP的实控和借贷入口调整到了慧聚科瀚。

慧聚科瀚的核心产品宜口袋，在暴雷之前继续暗地里维持着36%的高额放贷利率。

与此同时，两件事情开始同步进行。

1. 引导用户刷单并截留还款资金

一方面，平台开始进行前面提到的操作：

引导用户刷单，并截留用户的还款资金。

用户认为自己已经完成还款，APP也显示账单结清，但实际出资的持牌消费金融机构及银行并未收到相应资金。

2. 制造“虚拟人”进行借贷

另一方面，慧聚科瀚控制的宜口袋开始利用已有数据，大量制造虚假借款人——“虚拟人”。

利用这些“虚拟人”的身份在平台进行借贷。

银行放款后，这部分资金同样被挪用或截流到指定账户。

至此，资金已经准备就绪。

接下来，就是这场骗局的收尾阶段。

六、海外放贷业务与资金转移

桔子数科在2025年秘密从外部采购、部署了一套海外小额放贷服务，主攻墨西哥等市场。

通过一段时间的经营，该业务收集了一定数量的海外用户信息。

到了2026年6月，慧聚科瀚旗下的宜口袋自建了海外墨西哥放贷业务，同时将此前外采海外放贷服务所收集到的用户数据，全部导入宜口袋海外平台中。

随后，利用此前相同的手段，再次大量制造海外“虚拟人”。

利用这些“虚拟人”从宜口袋海外平台进行海量借贷、刷单，资金就这样顺利地从中国转移到了海外。

七、暴雷后的相关人员情况

在暴雷发生时，刘毅、曹洪亮及其家属在中国早已失联。

史孝东跑回营口，由地方保护伞保护起来。

至此，一场精心策划的庞氏骗局完美收场。

八、员工欠薪、裁员及债务规模

截至2026年7月20日，桔子数科已经拖欠员工工资一个多月。

大部分员工已经被通知裁员，公司无法立即兑现任何裁员赔偿。

目前桔子数科：

共计负债270亿元以上。

同时：

保守估计转移到海外的资金达到100亿元以上。

九、目前情况

目前，桔子数科正在立案审查中。

在这场庞氏骗局背后，受害者包括：

* 民间借贷用户；
* 资方；
* 员工；
* 甚至包括曾经为其背书的营口政府。

这些主体最终都成为了受害者。

唯一的赢家，只有策划这场骗局的幕后。
